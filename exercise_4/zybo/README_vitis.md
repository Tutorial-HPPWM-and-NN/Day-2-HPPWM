# Setup Guide: Vitis 2022.2 Project for TFLM on Zybo Z7-10

This document describes step by step how to create the bare-metal project
in Vivado and Vitis 2022.2 to run TFLite Micro on the ARM Cortex-A9 of
the Zybo Z7-10.

---

## Prerequisites

- Vivado 2022.2 with Zynq-7000 device support installed.
- Vitis 2022.2.
- Zybo Z7-10 connected via micro-USB data cable (not charge-only).
- TFmicroZynq repository cloned:
  `git clone https://github.com/SensorsINI/TFmicroZynq.git`
- Exercise 4 artifacts generated:
  - `model_data.cc` (generated by `exercise_4_solution.py` Step 2)
  - `main.cc` (this repository, `zybo/` folder)

---

## Step 1: Create the Hardware Project in Vivado

1. Open Vivado 2022.2.
2. **Create Project** → Next → RTL Project → Next.
3. **Default Part** → **Boards** tab → search **Zybo Z7-10** → select → Next → Finish.
   *(If it does not appear, click refresh and select Zybo Z7-10 v1.1. You can also dowload the files from [digilent](https://digilent.com/reference/programmable-logic/zybo-z7/start))*
4. **Flow Navigator** → **Create Block Design** → name `design_1` → OK.
5. Click **+** → search `Zynq7 Processing System` → double-click.
6. Click **Run Block Automation** → OK.
7. Connect the clock: drag `FCLK_CLK0` to `M_AXI_GP0_ACLK`.
8. **Validate Design** → OK (DDR warnings are normal for this board).
9. **Sources** panel → right-click `design_1` → **Create HDL Wrapper**
   → Let Vivado manage → OK.
10. **Generate Bitstream** → accept all → wait ~5-10 minutes.
11. **File → Export Hardware → Include Bitstream** → note the `.xsa` path.

---

## Step 2: Create the Platform in Vitis

1. Open Vitis 2022.2.
2. **File → New → Platform Project**.
3. Name: `zybo_platform` → Next.
4. Hardware Specification → Browse → select the `.xsa` file → OK.
5. Operating System: `standalone` | Processor: `ps7_cortexa9_0` → Finish.
6. Right-click the platform → **Build Project**.

---

## Step 3: Create the Application Project

1. **File → New → Application Project** → Next.
2. Select platform `zybo_platform` → Next.
3. Name: `hppwm_tflite` → Next.
4. Domain: `standalone on ps7_cortexa9_0` → Next.
5. Template: **Empty Application (C++)** → Finish.

---

## Step 4: Add TFLite Micro and Model Files

1. Copy the `TFmicroZynqSrc/` folder from the cloned TFmicroZynq repository to:
   `<workspace>/hppwm_tflite/src/`
2. Copy `model_data.cc` (from `exercise_3/artifacts/`) to:
   `<workspace>/hppwm_tflite/src/`
3. Copy `main.cc` (from this `zybo/` folder) to:
   `<workspace>/hppwm_tflite/src/`
4. In Vitis, right-click the **src** folder → **Refresh**.

---

## Step 5: Configure Build Settings

### 5.1 System project (`hppwm_tflite_system`)

Right-click → **C/C++ Build Settings** → Configuration: All configurations.

- **System Builder → Miscellaneous → Other flags:** add ` -std=c++2a`

### 5.2 Application project (`hppwm_tflite`)

Right-click → **C/C++ Build Settings** → Configuration: All configurations.

**Compiler → Directories → Include paths (-I):** add each of the following:
```
../src/TFmicroZynqSrc
../src/TFmicroZynqSrc/third_party/flatbuffers/include
../src/TFmicroZynqSrc/third_party/kissfft
../src/TFmicroZynqSrc/third_party/gemmlowp
../src/TFmicroZynqSrc/third_party/ruy
```

**Compiler → Defined Symbols (-D):** add:
```
TF_LITE_STATIC_MEMORY
```

**Compiler → Miscellaneous → Other flags:** add:
```
 -std=c++2a -fno-exceptions
```
*(Note: keep the leading space to avoid the flag merging with the previous one.)*

**Linker → Libraries (-l):** add:
```
m
```

Click **Apply and Close**.

---

## Step 6: Build

Right-click **hppwm_tflite_system** → **Build Project**.

The first build takes approximately 10 minutes (compiling TFLite Micro).
Subsequent incremental builds are fast (a few seconds).

---

## Step 7: Run on the Zybo

1. Verify that jumper **JP5** on the Zybo is in the **JTAG** position.
2. Connect the Zybo to the PC via micro-USB (PROG/UART port).
3. In Vitis: **Window → Show View → Terminal**.
4. Open serial terminal: green plug icon → Serial → select the Zybo COM port
   → Baud rate: **115200** → OK.
5. Right-click **hppwm_tflite** → **Run As → Launch on Hardware
   (Single Application Debug)**.
6. Read the angle predictions from the serial terminal output.

---


Copy the 17 predicted mrad values and use them in Step 4 of
`exercise_4_solution.py` for cross-validation.

## Troubleshooting

| Problem | Solution |
|---|---|
| `AllocateTensors() failed` | Increase `kTensorArenaSize` in `main.cc` (e.g. `256 * 1024`) |
| `FullyConnected per-channel quantization not yet supported` | Ensure you are using `model_pruned_int8_tflm.tflite`, not the standard Exercise 3 model |
| `Could not find ARM device` | Check JP5 jumper is in JTAG position and cable supports data transfer |
| Include errors during build | Verify all five paths in Step 5.2 are correctly added |
| Variable name linker error | Open `model_data.cc`, check the exact array name, update `extern` declarations in `main.cc` |
