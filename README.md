# Tutorial: Deep Learning and Edge Deployment for HPPWM - Day 2

This repository contains the practical material for the second day of the
tutorial, focused on using neural networks to approximate the HPPWM solution
space and deploying the resulting model on an embedded SoC platform.

The central objective is to replace massive lookup tables with compact neural
models trained on offline-generated datasets, and ultimately run inference on
the ARM Cortex-A9 processor of the Zybo Z7 in bare-metal mode.

## Repository Structure

The practical material is divided into four sequential folders. Each directory
contains a base script (`_base.py`) for in-class work, a complete solution
script (`_solution.py`), and a local instructions file (`exc_N.md`).

* **Exercise 1 (MLP Training):** Implementation of a multi-layer perceptron
  to approximate the switching angles from the SHC-PWM harmonic references.
  Includes data partitioning, input normalization, training and evaluation.
* **Exercise 2 (Model Compression):** Application of magnitude-based weight
  pruning to reduce the effective model complexity while preserving regression
  accuracy.
* **Exercise 3 (TFLite Quantization):** Conversion of the trained model to
  TensorFlow Lite with INT8 Post-Training Quantization (PTQ). Metrics are
  compared before and after quantization.
* **Exercise 4 (Zybo Z7 Deployment):** Reconversion of the model for TFLite
  Micro bare-metal compatibility, Vitis 2022.2 project setup, execution on
  the Zybo Z7, and cross-validation of PC vs hardware inference results.

## Dataset

The dataset used in this day is generated by Exercise 4 of Day 1 and must
be placed at `data/dataset_shcpwm_10000.csv` before running any exercise.

**Inputs:**
- `m1`, `m5`, `m7`, `m11`, `m13`, `m17`, `m19` — harmonic magnitudes
- `phi5` — phase reference for the 5th harmonic (radians)

**Outputs:**
- `alpha_1` to `alpha_17` — optimal switching angles (radians)

## Requirements

Python 3.9+ is required. Install all dependencies with:

```bash
pip install -r requirements.txt
```

## Exercise Dependency Chain

Each exercise builds on the artifacts generated by the previous one:

```
Exercise 1 → input_scaler.joblib
                mlp_fp32_weights.npz
                mlp_config.json
                    ↓
             Exercise 2 → mlp_pruned_fp32_weights.npz
                              ↓
                         Exercise 3 → model_pruned_int8.tflite
                                          ↓
                                     Exercise 4 → Zybo Z7 inference
```

Run the exercises in order. Each script will raise a `FileNotFoundError`
if a required artifact from a previous exercise is missing.
